# lvthn-web

> [!NOTE]
> A single-file browser encryption tool built on leviathan-crypto. Encrypts
> text and files entirely client-side using Serpent-256-CBC and Argon2id.
> No server, no installation, no network connection required after load.

---

## Demo

[leviathan.3xi.club/web](https://leviathan.3xi.club/web)

---

## Build

Requires [Bun](https://bun.sh).

```sh
bun install
bun bake
# → dist/index.html
```

The build bundles leviathan-crypto and argon2id into a single self-contained
HTML file. Drop it anywhere — it has no external dependencies at runtime.

---

## Usage

Open `dist/index.html` in any modern browser. No server required.

**Encrypt:** choose encrypt mode, provide text or drop a file, select a
passphrase or keyfile, click encrypt. Output is armored text or a binary
`.lvthn` file — your choice.

**Decrypt:** choose decrypt mode, provide the encrypted data, supply the
same key used to encrypt. The format is detected automatically from the
file header.

**Key generation:** the keygen panel generates 64 random bytes from
WebCrypto. Download as a binary keyfile or copy the hex — either works as
input on the keyfile tab.

---

## Cipher and key derivation

**Cipher:** Serpent-256-CBC + HMAC-SHA256 (Encrypt-then-MAC). Single-pass
AEAD via leviathan-crypto's `Seal` API.

**Passphrase path:** Argon2id with OWASP 2023 minimum parameters — 19 MiB
memory, 2 passes, 1 thread — producing a 64-byte key.

**Keyfile path:** HKDF-SHA256 expands the keyfile to 64 bytes. Any 32-byte
or larger binary file works as a keyfile. Keys generated by the keygen panel
or by `lvthn keygen` are both valid inputs.

---

## Wire format

Files produced by lvthn-web use the `LVWB` format, distinct from the CLI's
`LVTHNCLI` format. The two tools are not interoperable — a file encrypted
in the browser cannot be decrypted by `lvthn decrypt`, and vice versa.

```
Offset  Size  Field    Description
------  ----  -----    -----------
0       4     magic    "LVWB" (0x4c 0x56 0x57 0x42)
4       1     version  0x02
5       1     kdf      0x02 = keyfile (HKDF-SHA256)
                       0x03 = passphrase (Argon2id)
6       32    salt     Argon2id salt; all-zero for keyfile mode
38+     N     sealed   SerpentSeal output — IV(16) || ciphertext || HMAC(32)
```

## Code as reference

This demo is intentionally written to be read. The format constants, KDF
parameters, Encrypt-then-MAC construction, and HMAC input layout (header
with HMAC field zeroed, concatenated with ciphertext) are all documented
inline in `src/app.js`. Read it alongside the leviathan-crypto docs if
you want to understand how the pieces fit together.
